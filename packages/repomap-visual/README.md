# @frannn2114/repomap-visual

React components for visualizing repository architecture graphs generated by the Repomap skill.

## Components

- `GraphRenderer` - Main canvas with react-flow (interactive graph)
- `ChatPanel` - Local AI chat about the architecture  
- `ManualEditor` - Visual diagram editor
- `BranchProvider` / `useBranches` - What-if scenario branches
- `AlternativeViews` - Onion, Layers, Cluster, Pipeline views

## Types (re-exported)

- `RepoGraph`, `Node`, `Edge`, `GraphMeta`, `Overlay`
- `Branch`, `BranchDelta`, `ResolvedGraph`
- `ViewType`, `NodeType`, `EdgeType`, `DetectedPattern`, `LayoutTemplate`

## Installation (when npm available)

```bash
# From this monorepo root
cd packages/repomap-visual
npm install
npm run build
npm pack  # Creates @frannn2114/repomap-visual-1.0.0.tgz
```

## Usage in another project

```bash
npm install ./path/to/@frannn2114/repomap-visual-1.0.0.tgz
# Peer deps required:
npm install react react-dom @xyflow/react@12
```

```tsx
import { GraphRenderer, BranchProvider, type RepoGraph } from '@frannn2114/repomap-visual'
import '@xyflow/react/dist/style.css'  // Required!

function ArchitectureMap({ graphJson }: { graphJson: RepoGraph }) {
  return (
    <BranchProvider baseGraph={graphJson}>
      <div style={{ width: '100%', height: '100vh' }}>
        <GraphRenderer graph={graphJson} />
      </div>
    </BranchProvider>
  )
}
```

## Integration with Repomap Skill

The skill outputs `RepoGraph` JSON compatible 1:1 with these types:

```bash
opencode skill repomap serve --localPath ./my-project
# Returns { pid, url } → opens http://localhost:XXXX with graph preloaded
```
