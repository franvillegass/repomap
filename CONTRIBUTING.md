
# How can you contribute to RepoMap?

There are two ways:

- **Use it** — map your own project and share it online. Any diffusion of RepoMap is welcome!

- **Improve it** — use your technical skills to help build the application.

## Branch structure

This repo has two main branches:

- **`skill`** — contains the opencode skill (analyzer, CLI, skill instructions). All skill-related changes go here.
- **`visuals`** — contains the visualizer library source code (`@frannn2114/repomap-visual`). All visualizer changes go here.

Open your pull request against the branch that matches your changes.

## Did you find a bug?

If you found a bug, open an [issue](https://github.com/frannn2114/repomap-pipeline-v2/issues) describing the problem.
Include a title, a description, and a screenshot if possible.

## Did you write a patch?

If you fixed a bug or added a feature, open a pull request with your patch.
Make sure the PR description clearly explains the problem and your solution.

Any support that makes RepoMap grow is greatly appreciated!
